# 🧠 BlameDetector – AI 과실 분석기

**"우리 대화, 과실 몇 대 몇이야?"**

논쟁 중인 카톡 대화를 업로드하면,  
AI가 대화 내용의 감정/공격성/논리성을 분석해  
**누가 더 잘못했는지 과실 비율**을 내려주는 웹 서비스입니다.

> 🤳 10~30대를 위한 유쾌한 밈 기반 UX  
> 📱 모바일 최적화 / 📤 공유 기능 / 🧠 무료 AI 분석 기반  
> 🚫 로그인 없이 자유롭게 사용 / 💸 광고 기반 수익 모델

---

## 📸 예시 시나리오

- 친구와 카톡하다 싸움 → 캡처해서 업로드
- "이건 무조건 7:3이야!" → AI가 실제로 분석해줌
- 결과를 친구에게 공유: "봐봐 너가 더 잘못했대!"

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 이미지 업로드 | 카카오톡 대화 캡처 업로드 |
| OCR 처리 | 이미지 속 텍스트 자동 추출 (Tesseract.js) |
| 감정/공격성 분석 | Hugging Face 무료 모델 활용 |
| 과실 계산 | A/B 간 과실 퍼센트 계산 (룰 + 감정 분석 조합) |
| 결과 리포트 | 시각화 및 AI 판결 사유 제공 |
| 공유 기능 | 링크 복사 / 카카오톡 공유 등 |
| 광고 수익 모델 | 결과 리포트 화면에 광고 삽입 예정 (배너/네이티브 광고) |

---

## ⚙️ 기술 스택

| 영역 | 기술 |
|------|------|
| FE | React + Tailwind CSS (모바일 우선) |
| BE | Spring Boot + REST API (로그인 없음) |
| OCR | Tesseract.js (무료, 오픈소스) |
| AI 분석 | HuggingFace Transformers API (무료 모델 사용) |
| 배포 | Vercel (FE) / Render or EC2 (BE) |

## 🆓 AI API 사용 방침

- 현재는 **100% 무료 API** 기반으로 개발
- OCR: `Tesseract.js` (브라우저 기반 무료 OCR)
- 감정/공격성 분석: Hugging Face 무료 모델 사용
- 추후 수익 발생 또는 고도화 필요 시 유료 API로 전환 계획
